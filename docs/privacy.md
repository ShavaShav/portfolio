# Privacy

This site runs its own lightweight, first-party analytics. It exists only to
understand which parts of the site people find useful — there are no ads, no
profiles, and no data sales.

- **First-party only.** Usage data is collected and stored by this site alone.
  No third-party analytics services are involved.
- **No cookies.** The site sets no cookies, for analytics or anything else.
- **No third-party scripts.** No external trackers, tag managers, or ad
  scripts run on this site.
- **Session id in `sessionStorage`.** A random session identifier is kept in
  your browser's `sessionStorage`. It is discarded when you close the tab,
  is not a persistent cookie, and cannot follow you across other sites.
- **DNT / GPC honored.** If your browser sends a Do Not Track (DNT) or Global
  Privacy Control (GPC) signal, analytics is disabled for your visit.
- **No raw IP addresses.** Your IP address is never stored in raw form.

Run `privacy` in the site's terminal for the short version of this disclosure.
